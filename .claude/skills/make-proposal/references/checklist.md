# Чеклист перед сдачей КП

Проверить перед тем, как сказать «готово» / отдать клиенту.

## Стиль и брендинг

- [ ] Цвета строго из brief.md: primary-dark, accent, background-light. Никаких посторонних оттенков.
- [ ] Accent-цвет используется **точечно** — CTA, цифры метрик, бейджи, акцентные ссылки. **Не заливкой больших блоков.**
- [ ] Шрифты: display для заголовков (h1, section-title, метрики, заголовки модалок), body для всего остального.
- [ ] Чередование dark ↔ light между секциями — создаёт ритм. Не три cream подряд и не три dark подряд.
- [ ] Скругления карточек — 16px (radius), скругления pill-элементов — 100px.

## Контент

- [ ] Логотип в шапке белый (через CSS `filter: brightness(0) invert(1)`) — если SVG монохромный чёрный.
- [ ] Фото команды круглые, 80×80, в `.team-photo`.
- [ ] У каждого члена команды — короткая timeline опыта (опц. LinkedIn-ссылка).
- [ ] Логотипы клиентов (если есть) — grid 5×2 на dark-фоне.
- [ ] Портфолио — **3–4 кейса максимум**, выбранных под клиента. Не вываливай все 15.
- [ ] У каждого кейса: pill-бейдж категории, заголовок, 1-2 строки результата с цифрами, опц. ссылка «подробнее» в модалку.
- [ ] Контакты в футере (email, телефон, сайт).
- [ ] Co-branded header показывает «{ваша компания} × {клиент}».

## Текст без LLM-артефактов

- [ ] Прошёл grep из `llm-artifacts.md`:

  ```bash
  grep -nE "лежит в основе|нашего предложения|шаблон формата|близкий референс|это бьёт|ровно то|на встрече|вы сказал|Релевантно вам|точечный референс|в рамках предложения" <kp-file.html>
  ```

  Если что-то нашлось — переписать на конкретный факт.

- [ ] В тэгах кейсов — только функция/категория + год/формат. Нет «Релевантно вам».
- [ ] Нет фраз про «то, что мы обсудили» / «как вы говорили» / «ваша цитата».

## Технические проверки

- [ ] Все картинки ссылаются через относительный путь (`assets/logo.svg`, не абсолютный).
- [ ] HTML открывается в браузере без ошибок консоли.
- [ ] Адаптив проверен (`@media max-width: 768px` присутствует).
- [ ] Если standalone-версия — нет вшитых внешних `src=`, всё через `data:image/...;base64,...`:
  ```bash
  grep -E 'src=' <kp-standalone.html> | grep -v 'data:image'
  # должно быть пусто
  ```

## Язык и тон

- [ ] Язык brief.md (русский/английский/казахский) выдержан везде.
- [ ] Никаких эмодзи в HTML-выводе (только в внутренних заметках).
- [ ] Section labels вида `// Команда`, `// Портфолио` — uppercase, accent-цвет.

## Финальный шаг

- [ ] Открой готовый HTML в браузере (`open <file>.html`).
- [ ] Проверь хедер: «{твоя компания} × {клиент}» — оба написания правильные?
- [ ] Проверь цифры в метриках — это действительно твои цифры из brief, не плейсхолдеры?
- [ ] Проверь портфолио — все 3-4 кейса релевантны клиенту (по индустрии или формату)?
- [ ] Если нужен PDF — передай дальше скиллу `working-with-pdfs` или просто Print → Save as PDF.
