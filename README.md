# Proposal Template — собрать КП из звонка с клиентом

> Кейс из сессии AI Camp Almaty 2026. Skill, который превращает **транскрипт звонка с клиентом** в одностраничный HTML-КП в твоей айдентике.

## Проблема

Хороший КП — это 6-8 часов работы. Аналитик слушает звонок, выписывает SPSV (ситуация/проблема/решение/ценность), бегает за рынком, придумывает решение, согласует с командой, собирает HTML. Это типовая работа для аккаунта или сейлза-аналитика.

В большинстве компаний КП **либо не делают вообще**, либо **делают раз в полгода**, потому что собирать долго.

## Что делает skill

```
transcripts/<client>.txt (звонок с клиентом)
       ↓
[1. SPSV-extraction] — Ситуация / Проблема / Решение / Ценность + цитаты
       ↓
[2. Market research]  — компактный, 3-5 фактов с рынка про клиента и индустрию
       ↓
[3. Brainstorming]    — через superpowers:brainstorming, формируем РЕШЕНИЕ для клиента
       ↓
[4. Sketch]           — текстовый сценарий КП в чате на одобрение
       ↓
[5. HTML draft]       — рендер в твоих цветах, твоей команде, твоих кейсах
       ↓
[6. Standalone]       — base64-картинки, один файл для отправки
```

Каждый этап заканчивается **gate'ом** — skill показывает результат, ждёт «ок» или «скорректируй».

Время с момента «загрузил транскрипт» до «отправил КП» — **20-30 минут вместо 6-8 часов**.

## Три режима работы

Skill сам определяет режим по содержимому проекта:

| Что есть | Режим | Когда использовать |
|---|---|---|
| `transcripts/<client>.txt` | **Transcript-driven** (главный) | После discovery-звонка с клиентом |
| `brief.md` заполнен, транскрипта нет | **Brief-driven** | Входящая заявка без звонка, всё понятно из письма |
| Ничего | **Intake** | Первый запуск skill'а — настраиваем айдентику |

## Quick Start (Transcript-driven)

### Шаг 1. Один раз заполни brief.md
Это **постоянная часть** — информация о твоей компании (название, USP, identity, команда, кейсы, контакты).

```bash
cp brief.example.md brief.md
# открой brief.md в редакторе, замени значения на свои
```

### Шаг 2. Положи транскрипт звонка
После того, как у тебя состоялся discovery-звонок с клиентом:

```bash
# Получи транскрипт (через Otter / Fireflies / Notta / Whisper)
# Положи в проект:
cp ~/Downloads/akmelogistics-2026-05-19.txt transcripts/akmelogistics.txt
```

### Шаг 3. Запусти skill
В Claude Code:
```
/make-proposal собери КП из звонка с АкмеЛогистикс
```

Skill пройдёт через 6 фаз, на каждой будет gate с твоим подтверждением. Финал — открытый HTML в браузере.

## Попробуй на сцене / дома

В `transcripts/example-call-akmelogistics.txt` лежит **синтетический транскрипт звонка** — 22-минутный звонок между несуществующими компаниями Surfwave Analytics (BI-консалтинг) и АкмеЛогистикс (логистика). Используй его для тестового прогона прямо сейчас.

```
/make-proposal собери КП из transcripts/example-call-akmelogistics.txt
```

Через 20 минут — у тебя в браузере открывается КП в палитре `forest + amber + sand` (это палитра из `brief.example.md`, замени на свою).

## Несколько правил, чтобы КП работал

### 1. Co-branded header
В шапке всегда **«Твоя компания × Имя клиента»**. Это сразу показывает клиенту, что КП сделан под него лично.

### 2. Accent-цвет точечно
Accent-цвет — только для CTA, цифр, бейджей. Не заливай большие блоки.

### 3. Портфолио — 3-4 кейса, не 15
Skill сам отфильтрует под индустрию клиента.

### 4. Никаких эмодзи
В деловом КП эмодзи разрушают доверие.

### 5. Никаких LLM-артефактов
Фразы вроде «как мы обсудили», «это бьёт в боль X», «релевантно вам» — клиент это чувствует. Skill делает grep-проверку перед финалом.

### 6. SPSV — дословность над интерпретацией
Если клиент сказал «РОП говорит "всё нормально"» — пишем именно это, не «недостаточная коммуникация менеджмента».

## Что skill НЕ делает (специально)

- **Не генерирует цену и смету.** В шаблоне есть `<!-- Pricing section placeholder -->` — туда добавишь таблицу сам.
- **Не генерирует реквизиты.** Кладёшь в футер вручную.
- **Не подбирает фото за тебя.** Если хочешь фото команды — положи в `assets/team/`.
- **Не делает глубокий LinkedIn-research** ЛПР. Для этого — отдельный skill `enrich-and-pitch` в репо рядом.
- **Не пропускает confirmation gate'ы** — после каждой фазы ждёт твоего подтверждения.

## Monday Action — как внедрить у себя

1. **Скачай эту папку** (или клонируй репо `ai_camp_almaty`).
2. **Один раз заполни brief.md** на твою компанию.
3. **Настрой получение транскриптов** — Otter, Fireflies, Read.ai, Notta, или Whisper локально. Главное чтобы после звонка ты мог скопировать .txt в `transcripts/`.
4. **При новом клиенте**: после звонка кидаешь транскрипт → запускаешь skill → отвечаешь на gate'ах → получаешь КП.

Один раз настроил `brief.md` — дальше каждый КП пишется за 20-30 минут после звонка, без аналитика и копирайтера.
